SecureShare is a prototype for protecting image files using client-side AES-256-GCM encryption. Your encrypted file can be transferred to another device and unlocked using the secret key.

How SecureShare Works

01. Select Image

Select an image from your device that you want to protect.

02. Encrypt

SecureShare encrypts the image in your browser using AES-256-GCM.

03. Share & Unlock

Transfer the encrypted SecureShare file and share the 5-character secret key separately.

About SecureShare

SecureShare is designed as a prototype demonstrating secure image sharing through browser-based cryptography. The encryption and decryption happen locally in the browser.

How cross-device sharing works:
The encrypted image, IV, filename and file type are stored inside the downloaded .secureshare file. The secret 5-character key is NOT stored inside that file.

Send the .secureshare file to the receiver and communicate the 5-character key separately.
